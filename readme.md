### Dépendances ajoutés

```
pip install pandas numpy matplotlib jupyter
```

* Pandas : Pandas est une bibliothèque Python axée sur l’analyse de données, construite au-dessus de NumPy. Elle permet de manipuler des données tabulaires (similaires à des tables SQL ou Excel) de manière efficace et intuitive.
* Numpy : Bibliothèque Python essentielle pour travailler avec des données numériques
* Matplotlib: Matplotlib est une bibliothèque de visualisation en Python, qui permet de créer des graphiques à partir de données. Elle est particulièrement utile pour afficher des données sous forme de courbes, histogrammes, nuages de points, etc.
* Jupyter : Permet d'exécuter le notebook dans VS Code
